Software metrics provide objective signals for code health, delivery risk, and team performance. They are most useful when they are simple to calculate, clearly defined, and tied to actionable decisions.

## Complexity Metrics

- [Aggregate Complexity](/metrics/aggregate-complexity/)
- [Cognitive Complexity](/metrics/cognitive-complexity/)
- [Cyclomatic Complexity](/metrics/cyclomatic-complexity/)

## Other Software Metrics

- Bug Rate
- Code Coverage
- Cycle Time
- Defect Density
- Lead Time
- Maintainability Index
- Mean Time to Recovery
- Number of Open Bugs
- Rework Rate
- Team Throughput
- Technical Debt Ratio
